## 2. 为什么单服装 overfit 后必须进入双服装

O01 单服装 overfit 只能证明图像条件路径在一个固定服装上具有优化能力，不能排除网络把服装信息吸收到 decoder bias 或一套固定 residual 中。加入视觉差异明确的 O08，并在相同 target pose/camera 下交换 reference，才能把“会拟合一套服装”与“会依据 reference 选择服装”分开。

实验回答四个问题：

1. 同一个网络是否能平衡学习 O01 和 O08，而不是让一套服装支配更新或记忆一套固定 residual。
2. 固定 target pose/camera、只把 reference 从一种服装换成另一种服装时，feature、gate、Gaussian residual 和 render 是否随之变化。
3. 是否出现 reference 被忽略、两服装平均化、feature/residual/render 分层坍缩或 decoder bias 主导。
4. 双服装学习是否仍保持 fixed identity、protected regions、base/MMLP/backbone 冻结、target 不进服装 forward，以及 canonical multi-view consistency。

## 4. Outfit-balanced scheduler

正式一个 cycle 固定为：

1. `O01-front`
2. `O08-front`
3. `O01-back`
4. `O08-back`
5. `O01-left`
6. `O08-left`
7. `O01-right`
8. `O08-right`

这是 condition-major、outfit-interleaved round-robin。完整 cycle 后 O01/O08 optimizer update 数相等，四个 target view update 数相等；任意前缀的 outfit 计数差不超过 1，不会长期连续采样同一 outfit。`scheduler_index` 始终指向“下一 episode”，因此第 N 步 checkpoint 恢复后不会重放第 N 步。

state 保存：`scheduler_index`、`outfit_update_counts`、`per_view_update_counts`、`episode_update_counts`、`epoch_or_cycle_count`、`current_cycle_position`、`rng_state`、seed、完整 episode/outfit/target order 和 schedule fingerprint。load 会依据 index 重算计数并拒绝任何不一致。

## 5. Reference swap 评价

每个固定 target pose/camera 都生成四类 case：

- Correct：target outfit 与 reference outfit 相同。
- Swapped：target pose/camera 完全不变，只改为另一 outfit 的 references。
- Permutation：同 outfit reference 集合不变，只反转顺序。
- Dropout：三张 reference 分别去掉一张，形成三个 2-reference 诊断。

计划器显式验证 swapped case 的 target pose/Rh/Th/K/w2c/width/height fingerprint 与 correct case 相同，并保证 forward payload 只有 reference records 与 target pose/camera；`outfit_id`、`cloth_id`、target RGB/masks、Oracle/teacher 字段不会进入 Ours。

核心定义：

`reference_swap_margin = error(swapped references, correct outfit target) - error(correct references, correct outfit target)`

正值表示 correct reference 更好。逐 target/outfit/view 报告：correct-target error、swapped-target error、correct-vs-swapped render distance、reference sensitivity 和 outfit discrimination margin；每项再分 garment region、protected region、full foreground，以及 RGB、alpha、silhouette。

## 6. Conditioning-collapse 分类与指标

默认只报告统计，不在没有正式样本分布时冻结阈值。状态为 `THRESHOLDS_UNCALIBRATED_REPORT_ONLY`；负责人基于 smoke/milestone 分布批准阈值后，才允许产生最终自动分类。

| 状态 | 含义 |
|---|---|
| `COLLAPSE_FEATURE` | O01/O08 global/local features 几乎相同 |
| `COLLAPSE_RESIDUAL` | features 有差异但 residual 几乎相同 |
| `COLLAPSE_RENDER` | residual 有差异但 render 几乎相同 |
| `MEAN_OUTFIT_COLLAPSE` | 两个 target 都更接近平均服装而非自己的服装 |
| `REFERENCE_IGNORED` | 合法 reference swap 没有引起有效输出变化 |

指标清单：

- Global feature：cosine distance、normalized L2。
- Local anchor feature：observed、completed、garment-related anchors 的 mean/p50/p95，以及整体 cosine/normalized L2。
- Gate：geometry/appearance gate 的 distance、两侧 active fraction、active IoU、correlation。
- Residual：`delta_xyz`、`delta_log_scaling`、`delta_rotvec`、`delta_opacity_logit`、`delta_sh0`、`delta_shN` 各自的 bound-normalized L1/L2、cosine distance 和 active Gaussian overlap。
- Render：相同 pose/camera 下的 garment RGB distance、alpha distance、silhouette disagreement；LPIPS 只在正式环境已存在时启用，不在 prep 中安装依赖。
- Input sensitivity：reference RGB 合法替换后 feature、residual、render 的变化量。

## 9. Checkpoint/resume 合同

`save_two_outfit_checkpoint`/`load_two_outfit_checkpoint` 包装已有 full-training checkpoint，不创建 optimizer，只接收未来 runner 已创建的对象。checkpoint 必须包含：

- model state、optimizer state、LR scheduler state、AMP scaler state（如启用）
- global step、完整 RNG
- balanced episode scheduler state
- per-outfit、per-view、per-episode counts
- current cycle position/cycle count
- resolved config 与 config SHA256
- manifest SHA256
- base fingerprint
- trainable fingerprint

恢复顺序是验证方法/数据/optimizer group 合同，恢复 model/optimizer/LR scheduler/scaler/RNG，再恢复 balanced scheduler；恢复后的下一 episode、reference subset、target view、计数必须与不中断轨迹相同。

## 11. 验收与 PASS/FAIL

Engineering：所有 trainable groups gradient finite/nonzero；base/MMLP/backbone 冻结；target image 不进 forward；checkpoint/resume exact；O01/O08 update 完全平衡。

Learning：两套服装都有正 edit reduction；correct reference 分别接近自己的 target；correct 优于 swapped；feature/gate/residual/render 都有 outfit 区分度；不输出平均服装；protected/background 安全。

Visual：同一 target pose 下 reference 改变时输出服装随之改变；face/hair/hands/shoes 保持 subject02；四视角服装语义一致。

最终状态只允许：`TWO_OUTFIT_DISCRIMINATION_PASS`、`CONDITIONING_COLLAPSE`、`OUTFIT_AVERAGING`、`REFERENCE_IGNORED`、`ONE_OUTFIT_DOMINATES`、`ENGINEERING_FAILURE`。
