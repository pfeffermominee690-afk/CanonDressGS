## 2. 为什么必须区分 support 容量和 decoder 容量

Representation Triage 的 Rung-2 已证明原始共享 200k canonical Gaussian support 能在相同相机和 renderer 下表达 O01/O08，因此“点云是否能表示服装”与“条件网络能否产生正确 residual field”是两个不同问题。旧 Probe D 在可实现的 Oracle residual 上仍只有 `0.312990` normalized RMSE、`0.220043` outfit separation 和 `0.156142` garment render MAE；同时所有 latent、FiLM、shared decoder 与 head 梯度均有限非零且无 bound saturation。这把瓶颈定位在旧 decoder/parameterization，而不是 support 或梯度。

## 3. V7 架构

```text
frozen canonical Gaussian attributes + anchor assignment
        -> static support descriptor -> shared small support encoder
reference/global feature -----------------------------+
interpolated completed local feature (direct path) ---+-> concatenate
                                                        |-> geometry trunk
                                                        |    -> xyz head
                                                        |    -> scaling head
                                                        |    -> rotation head
                                                        +-> appearance trunk
                                                             -> opacity head
                                                             -> SH0 head
                                                             -> SHN head
six raw heads -> legacy-identical tanh/vector bound -> fixed-one probe gate
```

Geometry 和 appearance 只共享小型 support encoder；进入 residual trunk 后参数完全独立。六个 final head 均独立且严格零初始化。每个 trunk 使用 LayerNorm、SiLU 和 3–4 个 residual MLP block；local/global condition 在输入和中段各注入一次。LayerNorm 只沿单行 feature 归一化，因此不会因 chunk 边界改变语义。

## 4. Static support descriptor

每个 Gaussian 的 descriptor 仅由冻结 canonical support 构建：

- normalized canonical xyz；
- base log scaling、opacity logit、SH0；
- anchor interpolation 的 max weight、entropy、L2；
- 插值 canonical anchor xyz、Gaussian-anchor 差值与距离；
- canonical xyz Fourier encoding。

它不包含 outfit ID、target RGB/mask、target-view feature、teacher active mask 或 O01/O08 分支。descriptor 由 base 和 topology 可复建，作为非持久 buffer 不重复写入 checkpoint；其字段、维度、归一化中心和尺度写入正式 input audit。

## 5. 条件注入与 gate

V7 直接把 completed local anchor feature 插值到每个 Gaussian，再与 expanded global feature 和 support embedding 拼接。global condition 可用于调制但不替代 local path。Stage A 固定 `geometry_gate=appearance_gate=1`，将 gate 学习与 residual 容量隔离；模块保留显式 external gate 接口供后续正式方法使用。

## 6. 六属性 bounds 与损失

V7 沿用 legacy 合同：xyz `0.05`、log scaling `0.35`、rotation `0.2617993878`、opacity logit `2.0`、SH0 `0.25`、SHN `0.10`。raw head 经 `tanh`（rotation 使用同一 vector-norm 映射）再乘既定 bound。Oracle regression 在 bound-normalized residual space 中计算，Oracle tensor 冻结并 detach，只进入 loss/离线渲染，不进入 prediction forward。
