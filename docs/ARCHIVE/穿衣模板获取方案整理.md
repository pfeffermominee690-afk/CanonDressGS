# Clothed Template 获取方案整理

本文档整理“clothed template mesh 怎么得到”这个问题。

在我们的 dressable Gaussian avatar pipeline 中，template mesh 的作用是：

```text
决定 Gaussian points / anchor points / control points 初始采样在哪里。
```

对于 MMLPHuman 原始单服装任务：

```text
如果有 data_dir/gaussian/template.ply:
  使用该 template mesh。

如果没有:
  代码会用 SMPL-X big-pose mesh 生成一个 template.ply。
```

但 SMPL-X mesh 本质上是人体 body proxy，不是真正的带衣服外表面的 clothed mesh。

对于我们的多服装任务，理想情况下：

```text
body template:
  一套 shared identity body template。

clothing / clothed template:
  每套服装一个自己的 clothed template。
```

也就是说：

```text
G_body      从 shared body template 初始化
G_cloth_0  从 cloth_000 template 初始化
G_cloth_1  从 cloth_001 template 初始化
G_cloth_2  从 cloth_002 template 初始化
```

不过，每套服装都必须有 clothed template 并不是硬性要求。可以根据数据、服装类型和时间选择不同方案。

## 1. 是否每套服装都需要 clothed template？

结论：

```text
不是绝对必须，但宽松衣服强烈建议。
```

具体判断：

```text
紧身衣 / 普通 T-shirt / 普通裤子:
  可以先不用单独 clothed template。
  用 SMPL-X body region 作为 clothing Gaussian 初始化通常能跑通。

宽松 hoodie / 外套 / 长裙 / 大衣:
  最好有单独 clothed template。
  否则 Gaussians 初始贴在身体表面，训练需要把它们推到衣服外表面，难度更大。

拓扑差异大的服装:
  例如短袖 vs 长袖，裤子 vs 裙子。
  最好每套服装单独建 template。
```

推荐实践：

```text
第一版 MVP:
  不强依赖 clothed template。
  先用 SMPL-X region proxy 初始化 clothing Gaussians。

增强版:
  对每套服装构建 per-outfit clothed template。
```

## 2. 方案 A：直接使用数据集或已有工具提供的 template

### 核心想法

如果数据集或已有预处理流程已经提供：

```text
template.ply
canonical clothed mesh
reconstructed mesh
clothed scan
```

则直接使用它作为该套服装的 clothed template。

放置方式可以沿用 MMLPHuman：

```text
cloth_000/
  gaussian/
    template.ply

cloth_001/
  gaussian/
    template.ply
```

或者在我们的新 pipeline 中统一组织：

```text
cloth_templates/
  cloth_000_template.ply
  cloth_001_template.ply
  cloth_002_template.ply
```

### 输入

```text
已有 clothed template mesh
```

### 输出

```text
canonical clothed template.ply
```

### 优点

```text
最省事
最稳定
效果通常最好
不需要自己实现多视角重建
```

### 缺点

```text
依赖数据集或外部工具
不是所有数据都有
不同来源的 template 可能坐标系不一致
```

### 适合场景

```text
数据集已经提供 template
已有 AnimatableGaussians / 其他重建流程输出 template
需要快速跑通高质量实验
```

### 推荐程度

```text
如果有，优先使用。
```

## 3. 方案 B：用多视角某一帧重建 clothed mesh

### 核心想法

从一套服装视频中选一个姿态比较简单的帧，例如：

```text
A-pose
T-pose
站立正姿
身体遮挡少的一帧
```

使用这一帧的多视角图像和 mask 重建一个 posed clothed mesh，然后通过该帧的 SMPL-X pose 反变形到 canonical pose，得到 clothed template。

### 流程

```text
选择一帧 t
        ↓
读取该帧的多视角 RGB
        ↓
读取该帧的多视角 foreground / clothing mask
        ↓
读取 camera calibration
        ↓
使用 visual hull / multi-view stereo / 其他 3D reconstruction 方法
        ↓
得到 posed clothed mesh
        ↓
使用该帧 SMPL-X pose 做 inverse LBS / canonicalization
        ↓
得到 canonical clothed template
```

### 输入

```text
某一帧的多视角 RGB
某一帧的多视角 mask
相机参数
该帧 SMPL-X pose
```

### 输出

```text
该套服装的 canonical clothed template.ply
```

### 优点

```text
每套服装可以得到自己的真实外表面
比 SMPL-X proxy 更适合宽松衣服
实现难度低于多帧融合
```

### 缺点

```text
依赖这一帧的多视角覆盖质量
背面或遮挡区域可能不完整
pose 反变形可能引入误差
需要实现或调用多视角重建工具
```

### 适合场景

```text
每套服装都有同步多视角图像
有姿态简单的一帧
需要比 SMPL-X proxy 更好的初始化
但暂时不想做完整多帧融合
```

### 推荐程度

```text
适合作为增强版。
如果时间允许，可以优先给宽松衣服做这个。
```

## 4. 方案 C：融合多帧、多视角得到 canonical clothed template

### 核心想法

利用整段多视角视频的多帧观测，先把每一帧看到的 clothed surface 通过 SMPL-X pose 反变形到 canonical 空间，然后融合所有 canonical surface points，最后重建 mesh。

这是最接近论文中“从多视角视频获得 canonical clothed template”的完整路线。

### 流程

```text
多帧多视角 RGB / mask
        ↓
每帧相机参数
        ↓
每帧 SMPL-X pose
        ↓
对每帧估计可见 clothed surface
        ↓
使用 inverse LBS 反变形到 canonical pose
        ↓
融合所有 canonical surface points
        ↓
去噪 / 对齐 / 补洞
        ↓
Poisson reconstruction / TSDF fusion / mesh reconstruction
        ↓
得到 canonical clothed template
```

### 输入

```text
多帧多视角 RGB
多帧多视角 mask
相机参数
每帧 SMPL-X pose
```

### 输出

```text
更完整的 canonical clothed template.ply
```

### 优点

```text
覆盖更完整
能利用不同帧看到的不同表面区域
比单帧重建更稳
适合复杂服装
```

### 缺点

```text
实现复杂度最高
对 SMPL-X registration、camera、mask 质量非常敏感
需要处理多帧融合误差
需要点云去噪、mesh 重建、补洞
时间成本高
```

### 适合场景

```text
目标是高质量最终版
有足够工程时间
数据质量好
服装宽松且单帧重建不完整
```

### 推荐程度

```text
不建议作为第一版 MVP。
可以作为后续增强或论文补充实验。
```

## 5. 方案 D：不重建 clothed template，使用 SMPL-X 区域 proxy

### 核心想法

不额外重建 clothed template。

直接使用 SMPL-X / body template 上对应的服装区域作为 clothing Gaussian 的初始化区域。

例如：

```text
上衣:
  torso + upper arms

裤子:
  pelvis + legs

裙子:
  pelvis + upper legs
  可额外给 outward offset

鞋子:
  feet region
```

训练时让 clothing Gaussians 通过 learned offsets 从身体表面移动到真实衣服外表面。

### 流程

```text
读取 SMPL-X / body template
        ↓
根据服装类型选定 body surface region
        ↓
在该 region 上采样 clothing Gaussian points
        ↓
初始化 clothing anchor points / control points
        ↓
训练时通过 position offset 学习衣服外形
```

### 输入

```text
SMPL-X template 或 body template
服装类型 / 服装区域定义
可选: clothing mask 用于训练监督
```

### 输出

```text
clothing Gaussian 初始化点
不一定输出真正的 clothed template.ply
```

也可以为了兼容代码，将区域采样结果或裁剪后的 proxy mesh 存成：

```text
cloth_000_proxy_template.ply
```

### 优点

```text
最快
工程最简单
完全复用 MMLPHuman 的 template / LBS / 采样逻辑
不需要先解决 clothed surface reconstruction
适合快速跑通 body + clothing Gaussian pipeline
```

### 缺点

```text
初始化不贴合真实衣服外表面
宽松衣服效果可能较差
裙子、大衣、外套下摆难处理
训练需要更大 offset 才能拟合衣服
```

### 适合场景

```text
deadline 紧
先做 MVP
服装相对贴身
想先验证可换装 pipeline 是否可行
```

### 推荐程度

```text
第一版最推荐。
```

## 6. 四种方案对比

| 方案 | 是否需要额外重建 | 质量潜力 | 工程难度 | 是否适合 MVP | 适合服装 |
|---|---|---:|---:|---:|---|
| A. 直接用已有 template | 否 | 高 | 低 | 是 | 所有，如果数据提供 |
| B. 单帧多视角重建 | 是 | 中高 | 中 | 可选 | 宽松或复杂服装 |
| C. 多帧多视角融合 | 是 | 最高 | 高 | 否 | 复杂、宽松服装 |
| D. SMPL-X 区域 proxy | 否 | 中 | 最低 | 是 | 贴身或中等宽松服装 |

## 7. 多套服装的数据组织建议

如果每套服装都有自己的 clothed template：

```text
subject_x/
  body/
    template.ply

  cloth_000/
    gaussian/
      template.ply
      lbs_weights_grid.npz
    images/
    masks/
    smpl_params.npz

  cloth_001/
    gaussian/
      template.ply
      lbs_weights_grid.npz
    images/
    masks/
    smpl_params.npz

  cloth_002/
    gaussian/
      template.ply
      lbs_weights_grid.npz
    images/
    masks/
    smpl_params.npz
```

如果第一版使用 SMPL-X 区域 proxy：

```text
subject_x/
  shared_body_template.ply
  clothing_region_config.json
  cloth_000/
    images/
    masks/
    smpl_params.npz
  cloth_001/
    images/
    masks/
    smpl_params.npz
```

`clothing_region_config.json` 可以描述：

```json
{
  "cloth_000": {
    "type": "upper",
    "regions": ["torso", "upper_arm"]
  },
  "cloth_001": {
    "type": "lower",
    "regions": ["pelvis", "leg"]
  }
}
```

## 8. 对当前项目的推荐路线

考虑当前目标是尽快冲论文，建议：

```text
第一阶段:
  使用方案 D。
  不先做 clothed reconstruction。
  用 SMPL-X / body template 的服装区域初始化 clothing Gaussians。
  先跑通 body Gaussians + clothing Gaussians 的组合渲染。

第二阶段:
  如果某套衣服效果差，尤其是宽松服装，
  对这套衣服使用方案 B 做单帧多视角 clothed template。

第三阶段:
  如果有时间和工具，
  对所有服装使用方案 A 或 C，形成更强的最终 pipeline。
```

也就是：

```text
MVP:
  SMPL-X region proxy

Better:
  per-outfit single-frame clothed template

Best:
  per-outfit multi-frame fused canonical clothed template
```

## 9. 和论文写法的关系

论文中可以这样表述：

```text
For each outfit, our garment Gaussians are initialized either from a reconstructed canonical clothed template when available, or from the corresponding SMPL-X body regions as a proxy. This design allows our framework to support both high-quality garment templates and lightweight initialization without additional reconstruction.
```

中文意思：

```text
如果有重建好的 canonical clothed template，我们就直接从它初始化服装 Gaussian；
如果没有，则从 SMPL-X 对应服装区域初始化，作为轻量级替代。
```

这样写的好处是：

```text
既保留方法上限，
又不把 pipeline 绑定到复杂 clothed template reconstruction 上。
```

## 10. 仍需进一步确定的问题

```text
1. 你的数据是否已经有 template.ply 或 clothed scan？

2. 每套服装是否有同步多视角图像？

3. 是否存在姿态简单、遮挡少的一帧可用于单帧重建？

4. clothing mask 是否可靠？

5. 服装类型主要是贴身衣服，还是包括裙子、大衣、宽松外套？

6. 如果使用 SMPL-X region proxy，如何定义每套服装对应的 body regions？

7. 是否需要为每套衣服生成独立 lbs_weights_grid.npz，还是共用 body 的 LBS weight volume？
```

这些问题会决定第一版到底选方案 D，还是直接上方案 A / B。
