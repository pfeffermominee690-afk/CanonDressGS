\section{Conclusion}

We formulate a bounded wardrobe-editing problem for one fixed Gaussian avatar and five seen garments. Explicit teacher-derived canonical residual bases separate spatial representation from reference conditioning, while deterministic zero-output initialization gives the coefficient branch an auditable mean-garment starting point. The evaluation contract makes lookup alternatives, matched architecture/supervision controls, transductive view use, onboarding cost, and held-out failure evidence central to the claim.
