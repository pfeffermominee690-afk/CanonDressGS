\section{Related Work}

\subsection{Animatable Human and Gaussian Avatars}
Animatable human models factor a canonical representation from pose-driven deformation and rendering. Gaussian avatars make this factorization efficient by deforming and rasterizing explicit primitives, but the canonical state still reflects the captured clothing. CanonDressGS freezes the avatar, deformation, skinning, and renderer; it addresses only the canonical garment state needed to use that existing avatar.

\subsection{Garment-Aware Human Modeling and Editing}
Garment-aware reconstruction and editing methods model clothing as geometry, appearance, deformation, or a combination of these factors. Our setting is narrower than garment generation or virtual try-on: every realizable garment is first optimized as a valid endpoint on one fixed avatar. This restriction permits an explicit test of whether interpolation preserves Gaussian support and leads to the endpoint-selection formulation.

\subsection{Reference-Conditioned State Control}
Reference-conditioned systems infer a discrete state or continuous control from one or more observations. Our predictor uses frozen per-reference features and permutation-invariant set aggregation, but its deployed output is discrete: a raw coefficient is mapped to the nearest member of a registered endpoint bank. This distinction separates the demonstrated method from continuous garment regression and automatic mixed-reference composition.
